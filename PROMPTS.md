# Использованные промпты к ИИ

ИИ использовался для составления плана работы, генерации базового шаблона автотестов на `pytest` и оформления моих заметок в Markdown-файлы. Секреты, токены и пароли в промптах не передавались.

1. **План работы**
   > Помоги набросать пошаговый план для тестового задания QA-стажёра: Задание 1 (баги по скриншотам) и Задание 2.1 (API на Python + pytest + Allure + ruff), чтобы все файлы лежали в корне одного репозитория.

2. **Шаблон автотестов**
   > Сделай базовый шаблон автотестов на `pytest` + `requests`: фикстуры в `conftest.py` для регистрации нового пользователя, получения Bearer-токена и удаления созданных объявлений после теста, и заготовку `test_api.py` с примерами проверок и шагами Allure.

3. **Структура тест-кейсов**
   > Помоги оформить мой список проверок по ручкам API в таблицу тест-кейсов для `TESTCASES.md` с указанием техник тест-дизайна, предусловий и ожидаемых результатов.

4. **Оформление записей в Markdown**
   > Оформи мои записи по найденным багам (со скриншотов и из проверок API в Postman) в аккуратные Markdown-файлы `TASK1.md` и `BUGS.md` с таблицами и командами `curl`, а также помоги сверстать `README.md` с инструкцией по запуску.
